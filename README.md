# 览山 · Lanshan

Windows 桌面文件管理器，采用 macOS Finder 风格，支持多标签、双栏和详情面板。Tauri 2 + Rust + React 19 + TypeScript + Vite + Tailwind CSS 4；异步目录数据使用 TanStack Query，导航与布局状态使用 Zustand，确认弹窗使用 Radix Dialog。项目可独立安装依赖、开发与打包。

## 界面区域说明（从上到下）

为了方便讨论界面，下面给各块区域约定一个名称。这里的“右侧”指左侧导航栏右边的整个工作区；最右边显示选中文件信息的小栏单独叫“详情栏”。以后可以直接说“调整第 5 区搜索筛选栏”或“把第 8 区文件展示区加高”。

| 编号 | 区域名称 | 位置与识别方式 | 主要内容与作用 |
| --- | --- | --- | --- |
| 1 | 顶部菜单栏 / 窗口栏 | 工作区最上面的一行 | 菜单入口、双栏浏览开关、“文件操作”队列入口，以及最小化、最大化 / 还原、关闭窗口按钮。 |
| 2 | 标签栏 | 顶部菜单栏下面，带文件夹名称和“＋”的一行 | 切换、关闭或新建文件夹标签；右键标签可查看更多标签操作。 |
| 3 | 导航搜索栏 | 标签栏下面，显示当前文件夹名称的一行 | 左边是后退、前进、文件夹名称和项目数量；右边是列表 / 图标视图切换、详情栏开关和名称搜索框。 |
| 4 | 地址栏 | 导航搜索栏下面，显示完整文件夹路径的一行 | 上一级按钮、路径输入框、跳转按钮和刷新按钮。不要与底部显示文件夹层级的“路径栏”混淆。 |
| 5 | 搜索筛选栏 | 地址栏下面，带“范围、种类、扩展名、大小、修改时间”的一行 | 设置搜索范围和筛选条件、重置条件；选择包含子文件夹时出现“搜索子文件夹”按钮。 |
| 6 | 图标排列栏（仅图标视图） | 搜索筛选栏下面，带“排列”和“显示参考线”的一行 | 切换对齐网格 / 自由摆放、开关参考线、重新排列图标；列表视图不显示。 |
| 7 | 文件操作栏 | 文件内容区域顶部，带新建、重命名、复制等图标的一行 | 左边是新建文件夹、重命名、复制、移动、回收站等操作；右边是批量更名、分类整理、排序方式与升降序。 |
| 8 | 文件展示区 | 文件操作栏下面，占面积最大的中央区域 | 列表视图显示名称、修改日期、大小、种类；图标视图显示文件图标或缩略图。未打开目录、加载中、空文件夹和读取失败时，也在这里显示对应提示。 |
| 9 | 底部状态栏 / 路径栏 | 文件展示区最下面的一行 | 可显示文件夹层级路径、选中数量和无法读取数量，右侧提供全选、清除选择及“点号文件”开关；路径显示可在菜单中开关。 |

上表按垂直顺序编号；同一行的左右部分可以继续用“左边 / 右边”描述。例如：“第 5 区搜索筛选栏太挤”“第 7 区文件操作栏右边的排序按钮需要调整”“第 8 区改成更大的图标”。

另外几块区域不在中央内容的上下顺序里，单独这样称呼：

| 区域名称 | 位置与识别方式 | 主要内容与作用 |
| --- | --- | --- |
| 左侧导航栏 | 窗口最左边，顶部有“览山 / LANSHAN” | 从上到下是品牌区、个人收藏（系统常用目录）、我的收藏、位置（磁盘）和“打开文件夹…”入口。 |
| 右侧详情栏 | 文件展示区右边，顶部写“文件详情”或所选项目数量 | 选中单个项目后，从上到下是标题与关闭按钮、文件预览、快速预览按钮、名称与类型、信息区（种类 / 大小 / 修改时间 / 位置）、打开按钮；多选或未选择时显示摘要或操作提示。只在开启详情且对应窗格为当前窗格时显示。 |
| 文件操作队列面板 | 点击顶部“文件操作”后出现的浮动面板 | 从上到下是标题和暂停 / 收起按钮、任务列表（进度、错误、重试等）、底部记录清理区。 |
| 临时提示区 | 有消息时才出现 | 全局错误显示在标签栏下方；文件区域的搜索反馈、错误和通知显示在文件操作栏下方、文件展示区上方。 |
| 弹窗 / 右键菜单 | 执行对应操作时浮现在界面上 | 包括快速预览、批量更名、分类整理、新建 / 更名 / 回收站确认，以及文件或标签的右键菜单。 |

开启双栏后，每个文件窗格各有第 3–9 区；可称为“左窗格的地址栏”“右窗格的文件展示区”。窄窗口下双栏会改为上下排列，可称为“上窗格 / 下窗格”。双栏模式还会在文件操作栏下面增加“跨栏操作栏”，包含“复制到另一栏”“移动到另一栏”。

## 开发启动

需要 Windows 10/11、WebView2、Rust stable、Visual Studio C++ Build Tools、Node.js 及 pnpm。首次安装依赖后从本项目根目录启动：

```powershell
pnpm install --frozen-lockfile
pnpm tauri dev
```

桌面开发命令将启动 Vite（3006，端口被占用时直接失败）并编译 Rust。仅预览界面：

```powershell
pnpm dev
```

浏览器预览不读取本机文件，也不生成模拟文件。真实文件能力需要桌面模式。本文仅提供启动命令，不代表已经执行；各轮实际验证见后文及开发记录。

## 使用

- 点击侧栏常用位置或磁盘，或通过“打开文件夹”选择目录；每次启动重新选择授权位置。
- 面包屑、上一级、前进后退与地址栏导航。地址栏只访问已选择位置及其子目录；访问其他磁盘请先在侧栏选择它。
- 标签可新增、切换、关闭；保留各自的导航历史、窗格视图、搜索与选择。双栏各自导航，点击或键盘聚焦的窗格为当前窗格，侧栏作用于当前窗格。窄窗口中双栏上下排列。
- 单击选中，Ctrl 点击切换多选，Shift 点击连续选择，Ctrl+A 全选；箭头键导航，双击或 Enter 打开。列表、图标视图与文件详情可独立切换。
- 文件或空白区域右键打开菜单，也可使用菜单键 / Shift+F10；菜单支持方向键、Home/End、Enter、Esc。
- 搜索支持当前目录即时筛选或手动子目录检索，多关键词组合以及类型/扩展名/大小/修改时间筛选；按名称、日期、大小升降序排序，文件夹始终在前。
- 工具栏新建文件夹、重命名、批量复制/移动、移入回收站。可用选择器选目标，也可直接“复制/移动到另一栏”。剪贴板为览山内部剪贴板，剪切意图在加入队列后消费；失败项目可在队列中重试。
- 在应用内拖动所选文件到另一栏或文件夹，默认复制，按住 Shift 移动。拒绝拖到自身或子目录；同名目标进入失败状态，可改名重试。尚未提供系统资源管理器与览山之间的拖入/拖出。
- 所有修改排入共享操作队列，离开原标签后继续串行执行。任务显示等待、执行、完成、失败、取消、跳过；失败任务保留并继续下一项。支持暂停后续任务、跳过等待项、失败重试、目标改名后重试。
- 复制先扫描总大小，再反馈实际复制字节，支持扫描期及逐块取消。暂停队列不会暂停正在执行的操作；同卷移动、重命名和系统回收站步骤开始后不可中途取消。窗口正常关闭请求在仍有待执行任务时会被拦截。
- 回收站操作有应用确认及 Windows 系统对话框；若 Windows 提示永久删除，请取消。

| 快捷键 | 操作 |
| --- | --- |
| Alt + ← / → | 后退 / 前进 |
| Alt + ↑ | 返回已授权的上级目录 |
| Ctrl + F | 搜索当前目录 |
| Ctrl + T / W | 新建 / 关闭当前标签，最后一个标签关闭后回到空白标签 |
| Ctrl + Tab / Ctrl + Shift + Tab | 切换下一个 / 上一个标签 |
| Ctrl + Shift + D | 开关当前标签的双栏 |
| Ctrl + A | 全选当前窗格可见项目 |
| Ctrl + C / X / V | 应用内复制 / 剪切 / 粘贴所选项目 |
| 菜单键 / Shift + F10 | 打开右键菜单 |
| F2 | 重命名选中项目 |
| Delete | 请求移入回收站 |

## 文件边界与当前限制

- Rust 负责所有 IO，界面通过统一的类型化 IPC 调用。耗时操作在后台线程执行，操作串行处理；前端没有文件系统和 Shell 插件权限。
- 检查规范化的授权根目录和目标父目录，保护根位置，拒绝同名覆盖与复制/移动到自身目录。不会申请管理员权限。
- 复制可递归目录，开始前扫描并拒绝符号链接及联接；执行期间仍再次校验。取消或 IO 失败可能留下部分副本，会明确提示；不自动删除部分副本，重试时可换名。尚未保留全部 NTFS 元数据，运行中的源文件变化也可能影响大小和复制结果。
- 移动及更名使用 Windows MoveFileW 拒绝覆盖，支持同卷移动；跨卷移动会提示失败，可先复制并核对，再将源项目移入回收站。
- 不支持操作符号链接；EXE/COM/MSI/MSP/LNK 可由用户双击或“打开”显式启动，脚本及注册表等系统操作类型仍不直接执行。
- 回收站使用 Windows PowerShell 内置的 Microsoft.VisualBasic FileSystem（固定脚本，路径作为进程环境数据传入），不提供永久删除 API。UNC 与较长路径的回收站操作会拒绝，转由资源管理器处理。Windows 可能显示自己的确认或取消对话框。
- 常用目录通过 Tauri 的系统目录解析器读取，支持 Windows 已知文件夹位置；其他位置可使用“打开文件夹”选择。
- 当前已生成 Windows x64 NSIS 安装包，尚未执行安装验收；不包含签名、自动更新、文件监听、框选或撤销；已支持本地工作区布局与收藏保存。`bundle.active` 暂为 false。

## Tauri 版本约束

核心 Rust `tauri` 固定为 `=2.11.5`，前端 `@tauri-apps/api` 使用 `~2.11.1`，保持 major/minor 一致；补丁号无需相同。Rust 插件 dialog/opener 固定为 `2.7.3`/`2.5.5`，与当前核心兼容。更新依赖时须同步核对核心两端及插件要求，不使用无 minor 上限的 `tauri = "2"` 单独升级核心。

Rust 还显式约束 `tauri-runtime = 2.11.3`、`tauri-runtime-wry = 2.11.4`、`tauri-macros = 2.6.3` 与 `tauri-build = 2.6.3`，Cargo.lock 的 `tauri-codegen` 为 2.6.3。它们是配套发布组合，版本号本来不同，不应统一改成 2.11.5。这样避免核心 2.11 被传递依赖的宽松范围带到 runtime 2.12。请保留 Cargo.lock，升级时整体核对并执行 Rust 编译检查；`tauri info` 只证明所列版本可读，不证明 Rust 编译通过。

## 文件预览与空格快速查看

- 图标视图中的常见图片按进入可视区域加载缩略显示，使用授权后的原图，不额外生成磁盘缩略图缓存。详情栏显示图片、文本和可播放媒体。
- 选中一个项目按空格，或使用详情栏/右键菜单的“快速预览”。弹窗中可用左右箭头切换，空格或 Esc 关闭；关闭后焦点返回所选项目。文件夹和不支持的格式显示信息。
- 图片支持适应窗口、原始尺寸与 25%–300% 缩放；透明背景使用棋盘格。
- 支持 PNG/JPEG/GIF/WebP/BMP/ICO/SVG/AVIF 等图片，实际解码取决于设备能力；HEIC、TIFF、PSD、RAW 等未引入解码器。
- TXT、JSON、CSV、日志及常见源码按纯文本展示，可自动换行与选择复制；Markdown 提供原文/效果双模式。识别 UTF-8、带 BOM 的 UTF-16，尝试 GB18030；不执行 HTML 或脚本；Markdown 的原始 HTML 默认忽略。文本最多读取前 256 KiB，截断时提示，二进制内容或未知编码提供失败状态。
- PDF 先校验 `%PDF-` 文件头，再由 WebView 内置查看器加载；Office 文档、压缩包等仍使用默认应用。内置 PDF 查看器有自己的焦点和按键处理，必要时点击弹窗顶部关闭按钮；不能将编译通过视为 PDF 已实机渲染通过。
- MP3/WAV/OGG/FLAC/M4A/AAC/Opus 和 MP4/WebM/MOV/M4V/OGV 使用系统支持的媒体播放能力，无自动播放。容器受支持不保证其内部编码可播放，失败显示恢复操作。
- 音视频控件、文本选区、输入框和其他弹窗不会被文件快捷键抢占。

安全边界：只在 Rust 规范化并验证已授权目录中的普通文件后，按格式白名单为该单文件增加 asset 只读作用域；静态 asset scope 为空，未开放通配目录或任意文件插件权限。音视频通过内置 asset Range 支持按需读取；文本限量读取经类型化 IPC 返回。预览状态仅存于内存查询缓存。

本轮 `pnpm typecheck` 与独立 target 目录的 `cargo check --locked --offline` 均已通过；没有启动应用、运行前端完整构建或桌面视觉验收。待验收：透明/大图与损坏图片、中文文本与截断边界、PDF 内置查看器、媒体编码、双栏与标签切换、空格和输入焦点，以及默认应用打开失败。

## Markdown 原文与效果

详情栏和空格快速预览中的 `.md` / `.markdown` 默认显示“效果”，可切换到“原文”。两种视图保留各自滚动位置；原文为只读文本，支持选择复制和自动换行，模式标签可用方向键操作。

效果视图使用 [react-markdown](https://github.com/remarkjs/react-markdown) 与 [remark-gfm](https://github.com/remarkjs/remark-gfm)，支持标题、粗体/斜体、删除线、列表、只读任务清单、引用、表格、链接、脚注及围栏代码块。代码块显示语言并提供复制，代码和表格可横向滚动，长文本不会挤出预览区域。

- 相对路径图片通过 Rust 已有授权范围及单文件 asset 读取；外部图片和绝对路径图片不会自动加载，避免隐式外部请求或扩大目录授权。
- 标题链接在当前文档定位，相对文件链接经原有安全打开接口处理；HTTP/HTTPS 网页链接仅在点击后交给默认浏览器，不允许其他协议或含登录凭据的地址。
- 不启用原始 HTML、脚本、MDX 执行、Mermaid 或数学公式插件；源文中的原始标记可在“原文”查看。
- 沿用 256 KiB 文本读取上限，截断文档会提示，末尾效果可能不完整。

检查：`pnpm typecheck`、Rust `cargo check --locked --offline` 以及 `pnpm check:markdown`（9 项 SSR 断言）均已通过。SSR 检查使用现有 Vite 的 esbuild 编译辅助进程，不启动应用，不读取用户文件；桌面点击、滚动和实际本地图片仍待实机验收。

## 增强检索与分类整理（2026-11-03）

搜索框支持空格分隔的多个关键词（全部匹配，不区分大小写）。筛选栏可组合种类、扩展名（如 `.pdf, docx`）、文件大小（≤1 MiB / ≥100 MiB）和修改时间。文件夹不参与大小筛选，点号文件开关继续生效。

范围选择“包含子文件夹”后，点击“搜索子文件夹”或在名称框按 Enter 执行。结果显示完整路径，右键可打开所在文件夹。此功能不读取文件内容、不创建全盘索引，也不跟随符号链接或 Windows 联接。单次上限：扫描 30,000 项、返回 2,000 项、深度 32，循环检查约 3 秒预算；个别系统 IO 阻塞不能被时间预算抢占。达到任何上限会提示结果不完整，请缩小范围。类型/扩展名/大小/时间筛选应用于已返回的结果，空名称可检索后按条件筛选。修改搜索词后须再次提交；重置会回到当前文件夹。搜索缓存仅内存保存，文件任务结束会使当前搜索重新读取。

在当前文件夹范围点击“分类整理”：有选择时整理所选项目，没有选择时整理筛选后的可见文件；只处理当前层普通非点号文件，跳过文件夹和链接，每次最多 500 个文件。可选按文件类型或按修改月份分组（本地日期，未知日期单列），预览目标文件夹、移动清单和冲突；点击“移动 N 个文件”后才写入队列。已有普通分类目录可复用；目标同名或分类位置被文件/链接占用的项目保留原位。不会递归整理代码目录或删除文件。

新建分类目录与其移动任务存在依赖：创建失败、被取消或跳过时，依赖移动会跳过；独立分类继续执行。队列仍拒绝覆盖目标，实际执行失败会保留错误。整理可以部分成功，不是文件系统事务，也没有一键撤销；失败后核对队列及原目录，再重新预览。预览不会锁定磁盘，预览后外部修改可能导致执行时失败。

外观采用 Finder 布局和 CSS 玻璃材质：雾蓝侧栏、半透明工具栏、标签和圆角控件，内容区域保持清晰底色；兼容 reduced-motion、reduced-transparency 和 forced-colors。属于 Windows WebView 内的视觉模拟，不依赖 macOS 原生材质。

检查命令：`pnpm typecheck`、`pnpm check:search-organize`（13 项隔离断言，模拟全部队列 IO），以及独立 target 的 `cargo check --locked --offline`。未启动桌面应用或实际执行用户文件整理；视觉、搜索大目录和真实文件操作仍待实机验收。

后续建议和优先级详见指定开发目录的 `览山/tasks.md`：批量重命名和工作区/收藏保存见下一节；其余建议为系统集成、跨卷移动、目录监听与大列表优化，再考虑内容索引、重复文件及撤销。

## 批量重命名、收藏与布局恢复（2026-11-03）

在当前目录选择 2–500 个普通文件，通过“批量更名”或右键“批量重命名…”打开预览。支持添加前后缀、区分大小写的字面查找替换（全部匹配，不支持正则）、统一名称加递增序号；默认保留最后一个扩展名，序号按当前筛选/排序后的列表顺序生成。预览同时显示新旧名称、未改变项和错误项。

名称会检查 Windows 保留名称、无效字符、UTF-16 长度、已有目标和批次内重复。冲突项目不加入队列；仅修改大小写、交换名称和需要其他源文件先更名才能腾空的目标暂不处理。点击“更名 N 个文件”才执行；仍由 Rust 队列在执行时校验路径和拒绝覆盖。更名可部分成功，暂不提供一键撤销。子目录检索范围内不开放批量更名，请先打开所在目录。

侧栏“我的收藏”可收藏当前目录、打开和逐项移除；大小写、常见路径分隔符和 Windows 扩展路径前缀会归一去重，最多 40 个收藏。打开收藏仍作用于当前窗格。

工作区自动保存在当前 WebView 的 localStorage（`lanshan.workspace.v1`），下次加载恢复标签、活动标签/窗格、双栏、列表/图标视图、详情栏开关、每栏最多 30 条导航历史和收藏。最多 12 个标签；损坏数据、未知版本和越界索引回退默认布局并提示，存储不可用或超出 512,000 字符时显示失败提示且可继续浏览。不保存选中文件、筛选、队列、剪贴板或文件预览。

保存目录路径不等于保存文件授权。应用重启后，Rust 授权仍为空；恢复的标签/收藏若无法读取，可点击“重新选择文件夹授权…”，或点击侧栏已知位置/磁盘授权。重新选择同一目录也会触发读取刷新。

新增检查命令 `pnpm check:rename-workspace`：33 项更名/存储隔离断言及一次模块重新加载恢复断言。文件条目和 localStorage 均为内存数据，不更名真实文件。当前 typecheck 和该脚本通过；未启动桌面应用、执行真实更名或视觉验收。本轮没有修改 Rust、依赖版本或锁文件。

## 图标网格、参考线与自由摆放（2026-11-03）

切换到图标视图后，排列工具条提供：
- **对齐网格**：图标按当前排序自动排列，固定单元间距。
- **自由摆放**：同一栏内拖到空白处或普通文件图标处，只移动图标坐标，不复制/移动磁盘文件。多选时一起摆放，保留相对距离；靠近文件区域边缘可滚动。图标可叠放，键盘聚焦的图标会显示在上层。
- **显示参考线**：独立开关，不改变排列模式；关闭参考线不会自动解除网格约束，选择“自由摆放”才可随意放置。
- **重新排列**：清除当前文件夹保存的坐标，按当前排序重新分配位置；自由模式保持自由，之后仍能拖动。切换为网格模式本身不会清除保存的自由位置。

自由摆放时，拖到未参与本次拖动的普通文件夹上，仍使用既有文件操作（默认复制、Shift 移动）；拖到另一栏也继续文件传输，不会修改目标栏的图标坐标。系统外部拖入限制保持不变。列表视图保持原有行为。

自由模式下在文件图标聚焦时，Alt+方向键移动所选图标 10px，Alt+Shift+方向键移动 50px；此时 Alt+方向键用于位置微调，列表/自动网格中的导航快捷键保持原样。文件位置限制非负坐标。筛选不重排被隐藏项目的已存坐标；新文件会避开已有自由图标，放到空闲格位。改变窗口大小不会缩放或删除已保存的位置，超出可见范围时只在文件区域内滚动。

每个文件夹独立保存模式、参考线和坐标，同一目录在多个标签/双栏共享设置。本地存储键为 `lanshan.icon-layouts.v1`；仅保存最近调整的最多 100 个目录，每目录自由摆放最多支持 2,000 个项目，总序列化大小最多 1,000,000 字符。超过项目数时仍能浏览，回退自动网格；存储格式损坏或保存失败有提示。子目录搜索结果使用自动排列，不记录混合目录的自由位置。没有改动 Rust 文件授权或文件操作 API。

检查：`pnpm typecheck` 和 `pnpm check:icon-layout` 通过；后者包含 26 项坐标/拖放分流/存储断言，加 1 项模块重载恢复断言，全部使用测试数据。未启动应用、执行真实文件操作或桌面拖动验收。

## 应用打开和 Windows 原生图标（2026-11-03）

修复 EXE、COM、MSI、MSP、LNK 被旧接口主动拒绝的问题。这些文件现在通过双击、Enter、右键打开或详情按钮交给 Windows Shell；使用文件所在目录作为工作目录，文件路径和目录分别传参，不拼接命令、不附加参数。MSI/MSP 由系统关联的安装程序处理，快捷方式由 Windows 解析；Windows 可能显示其正常授权对话框。调用成功仅表示 Shell 接受请求，不保证目标应用后续正常运行。BAT/CMD/PowerShell/注册表等原先不开放的类型保持拦截。

上述五种类型通过 Windows SHGetFileInfoW 读取自身或系统关联的图标，原生后台绘制 32×32 RGBA，再由前端生成 PNG 内存图片；兼容透明通道及旧式图标蒙版。读取图标不会启动目标程序。列表、宫格、详情和快速预览共用 Glyph；按进入可视区域加载，查询以路径/大小/修改时间去重缓存。图标失败或 Shell 不支持的长路径回退现有类型图标，不阻止文件浏览。不增加依赖、Shell 插件或 CSP 权限，继续检查已授权目录。

相关原生契约：[SHGetFileInfoW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shgetfileinfow)、[CreateDIBSection](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-createdibsection)、[DrawIconEx](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-drawiconex)。HICON、位图、DC 和 COM 生命周期在原生层释放。

验证：typecheck 和独立 target 的 cargo check --locked --offline 通过。另从真实 application.rs 提取原生实现构建只读探针，成功读取系统 cmd.exe 图标，验证尺寸、字节数及透明/非透明像素；没有启动 cmd.exe 或用户程序。初次探针发现混用正反斜杠导致 Shell 失败，规范化后成功。实际双击启动、安装器/UAC、快捷方式目标及桌面图标显示仍待实机验收。需要重启 Tauri 原生进程加载新命令；单纯刷新前端不加载 Rust 变更。
